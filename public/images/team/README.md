# Team photos

Drop headshots here, then set the `photo` field for the matching member in
`src/data/content.ts` (e.g. `photo: "/images/team/founder-1.jpeg"`).

Cards render a 4:5 portrait, so images are cropped to that aspect with
`object-cover`. Recommended: 800×1000px or larger, JPG or WebP.

Expected filenames (one per member id):

- founder-1
- founder-2
- data-analyst
- ml-engineer
- wordpress-developer
- digital-strategist
- project-manager
